# Adam AI Skills

Bộ skill miễn phí, viết bằng tiếng Việt, cho Claude (Claude Code, Claude app) và các agent đọc được định dạng `SKILL.md`. Do [Adam Uses AI](https://adamusesai.com) soạn từ việc làm hằng ngày.

Free Vietnamese-language agent skills for Claude and any agent that reads the `SKILL.md` format. Made by [Adam Uses AI](https://adamusesai.com).

## Cài đặt / Install

**Claude Code:** chép thư mục skill vào `~/.claude/skills/` (hoặc `.claude/skills/` trong dự án).

```bash
git clone https://github.com/adamwang99/adam-ai-skills
cp -r adam-ai-skills/skills/* ~/.claude/skills/
```

**Claude app:** nén một thư mục skill thành `.zip` rồi tải lên trong phần Skills (nếu tài khoản của bạn cho phép).
